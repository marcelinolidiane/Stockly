# Stockly

### Sistema de Controle de Estoque

O Stockly é um sistema desenvolvido para facilitar o controle de estoque, permitindo cadastrar produtos, registrar entradas e saídas e acompanhar as movimentações de forma organizada.

### Funcionalidades

* Cadastro, edição e exclusão de produtos
* Controle de entradas e saídas
* Consulta de produtos cadastrados
* Visualização do estoque disponível
* Histórico de movimentações
* Exportação de dados para Excel

### Tecnologias Utilizadas

| Tecnologia | Finalidade                 |
| ---------- | -------------------------- |
| Python     | Desenvolvimento do sistema |
| Flask      | Aplicação web              |
| SQLite     | Banco de dados             |
| Pandas     | Manipulação de dados       |
| OpenPyXL   | Exportação para Excel      |

### Sobre o Desenvolvimento

O projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos de programação e banco de dados, criando uma ferramenta funcional para o gerenciamento de estoque no dia a dia.
